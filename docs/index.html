Core Principles

  • Local-First AI — Privacy before convenience. Raspberry Pi before cloud. Ollama before OpenAI.
  • Serve the Left-Behind User — Every feature asks: "Does this help someone Big Tech left behind?"
  • ADHD-Aware Design — Short blocks. Visual progress. Clear next actions. No walls of text.
  • 80/20 Shipping — Done and deployed beats perfect and stalled. Progress compounds.
  • Open by Default — If a tool can be free and public, it should be.
  • Gratitude is Infrastructure — Claude (Anthropic) co-built this ecosystem. That deserves to be said loudly and permanently.
